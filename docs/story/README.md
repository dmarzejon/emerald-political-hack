# Story bible: *The Least Heir*

Working title for the political-thriller hack of Pokémon Emerald. This folder is the
source of truth for story. Map, dialogue, balance and features work should follow it;
when they need something it doesn't cover, ask for it to be added here rather than
inventing it in place.

## Quick reference for other threads

| Need | Answer |
| --- | --- |
| First sibling (Gym 1) | **Prince Corwin**, ninth child of the king |
| Gym 1 type | **Normal** |

Map slots are suggestions so the map thread can reuse Hoenn layouts. The map thread owns
the final choice.

## Tone

Political thriller first, Pokémon adventure second. People lie, bargain and posture.
Battles are the formal, legal way heirs settle disputes, so they matter politically, not
just as sport. Keep it readable for a Pokémon audience: no gore, menace stays implied,
and humour comes from courtiers and townsfolk. Every sibling should be someone the player
can understand, even the ones who never redeem themselves.

## Open questions for D

1. **Player gender.** The premise says "he". Draft assumes a fixed male prince with a
   player-chosen name (default *Rowan*). Keep Emerald's boy/girl choice and write
   "prince/princess" variants instead?
2. **Ending.** Draft ends with the player refusing the crown and founding a council of
   the ten towns (see [acts.md](acts.md#ending)). Prefer the player taking the throne?
3. **Legendaries.** Draft uses Darkrai (the cult's sleeper) and Cresselia (the player's
   mother's legacy). Fine to swap if balance wants Hoenn legendaries.
